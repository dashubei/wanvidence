## 書き直しの規則

### 1. 一文を割る

長い文は、たいてい2〜3の主張が接続助詞でつながっている。分ける。

**悪い**（78字）:
> 社会化期は生後3〜16週とされており、この時期に多様な刺激に接した子犬は、
> 成犬になってから恐怖や攻撃性を示しにくいことが複数の研究で示されているが、
> ワクチンが未完了の時期と重なるため、感染リスクとの兼ね合いが問題になる。

**良い**（3文、各30〜40字）:
> 社会化期は生後3〜16週です。この時期にいろいろな経験をした子犬は、
> 大人になってから怖がりや攻撃的になりにくい。複数の研究がそう示しています。
> ただしこの時期は、ワクチンがまだ終わっていません。感染の risk とどう釣り合わせるかが問題になります。

### 2. 漢字を開く

| 閉じる（漢字） | 開く（ひらがな） |
|---|---|
| 〜する事 / 〜出来る | 〜すること / 〜できる |
| 〜と言う / 〜為に | 〜という / 〜ために |
| 従って / 又は / 及び | したがって / または / と |
| 更に / 既に / 全て | さらに / すでに / すべて |
| 予め / 概ね / 尚 | あらかじめ / おおむね / なお |
| 行なう / 用いる | する / 使う |
| 〜に於いて / 〜に関して | 〜で / 〜について |

**ただし専門用語の漢字は開かない**（「拮抗条件づけ」を「きっこう条件づけ」にしない）。

### 3. 専門語は「日常語 → 専門語」の順で出す

**悪い**:
> <Term desc="...">拮抗条件づけ</Term>と<Term desc="...">系統的脱感作</Term>を組み合わせる。

**良い**:
> 怖がっているものを「いいことが起きる合図」に変えていきます。
> 同時に、平気でいられる距離から少しずつ近づけます。
> 前者を<Term desc="怖いものを、いいことと結びつけて印象を変える方法">拮抗条件づけ</Term>、
> 後者を<Term desc="平気な距離から少しずつ慣らしていく方法">系統的脱感作</Term>と呼びます。

**先に何をするのかを日常語で書き、あとから名前を付ける。**
読者は名前を覚えなくても行動できる。名前は獣医に相談するときに使う。

### 4. 抽象名詞を動詞に戻す

| 悪い | 良い |
|---|---|
| 環境の整備を行う | 環境を整える |
| 適切な対応が必要である | こうします（具体的に書く） |
| リスクの低減に寄与する | 危険が減る |
| 実施を推奨する | やってください |

### 5. 主語を省かない

日本語は主語を落とせるが、**誰が何をするのかが曖昧になると読者は迷う**。
「犬が」「飼い主が」「獣医師が」を明示する。

### 6. 変えてはいけないもの

- **数値・出典・エビデンスバッジ**（1文字も変えない）
- **「確認できていない」「裏が取れなかった」という留保**（薄めない）
- **章の構成・節の順序**
- **コンポーネントの構造**（KeyPoints / Deep / Disputed 等）
- 論争の両論併記

**平易にすることと、正確さを落とすことは違う。**
分からなくするより、長くなってもよい。**分量が1割増えても構わない。**

## 追加規則（依頼者の指摘による・2026-08-27）

依頼者から追加の指摘があった。

> 「楽観的な判断のかたよりを示した」等の言葉が、具体的にどういうことなのか分かりづらい。

**言い換えるだけでは足りない。** 抽象的な概念は、言い換えても抽象的なままである。

### 規則6: 研究の結果を書くときは、「何をどう測ったか」を先に書く

読者が「だから何?」と思う文は、たいてい**測り方が書かれていない**。

**悪い例**（実際に05章にあったもの）:
> ノーズワークを行った犬は、あいまいな位置に置かれた鉢に近づくまでの反応時間が短くなり、
> これは「より楽観的な判断のかたより」を示すと解釈されました。

読者の反応: 「鉢に速く近づいた。……で、それが何?」

**良い例**:
> この実験では、まず犬に2つの場所を覚えさせます。
> 部屋の左端に鉢を置いたときは中におやつが入っている。右端のときは空っぽ。
> これを繰り返して覚えさせたあと、**どちらでもない真ん中に鉢を置きます。**
>
> ここで犬が速く近づけば「入っているかもしれない」と期待している、
> ゆっくりなら「どうせ入っていない」と構えている、と読み取ります。
> **気分がいいときほど、あいまいなものを良いほうに期待する** ——
> 人間でも同じことが起きるので、これを気分の指標として使うわけです。
>
> 嗅ぐ活動をした犬は、この真ん中の鉢に**速く近づきました。**

長くなる。**それでいい。** 分からない短い文より、分かる長い文を選ぶ。

### 規則7: 用語の説明は「それは何か」で止めず「どう見えるか」まで書く

`<Term desc="...">` の説明が名前の言い換えで終わっているものが多い（全197語中72語）。

| 現状（言い換えだけ） | あるべき姿（どう見えるか） |
|---|---|
| 分離不安 = 留守番中にパニックになる状態 | 飼い主が出ていった直後から吠え続ける、ドアや壁を壊す、よだれで床が濡れるほどになる。留守番が「寂しい」のではなく、パニック発作に近い |
| 宥和行動 = 争いを避けてなだめる仕草 | 目をそらす、あくびをする、鼻をなめる、体を弓なりにして遠回りに近づく。「怒っていない」と伝えようとしている |
| 遅延模倣 = 見た動作を後から再現すること | 飼い主がバケツを回すのを見せ、10分後に「さっきと同じことをして」と指示すると、犬がバケツを回す |

**判断の目安**: その説明を読んで、読者が**その場面を思い浮かべられるか**。
浮かばないなら、まだ言い換えの段階で止まっている。

ただし**体の部位や物の名前は短くてよい**（味蕾、嗅上皮、ペットタクシーなど）。
説明が必要なのは**概念・現象・手続き**である。

### 規則8: 「〜性」「〜化」「〜的」で終わる言葉を疑う

これらは抽象名詞の目印である。見つけたら、**具体的な動作や場面に置き換えられないか**を考える。

| 抽象的 | 具体的 |
|---|---|
| 社会化を行う | 生後3〜14週のあいだに、いろいろな人・音・場所を経験させる |
| 攻撃性を示す | 唸る、歯を見せる、噛みつこうとする |
| 主体性を保証する | 犬が「やりたくない」と離れたら、追いかけない |
| 予測可能性を高める | 毎日だいたい同じ時間に、同じ順序でやる |

## 平易化は2段階に分ける（16章で分かったこと）

記録日: 2026-08-27

16章を1回書き直した結果、こうなった。

| 指標 | 前 | 後 | 目標 |
|---|---|---|---|
| 一文平均 | 59.4字 | **53.1字** | 40〜50字 |
| 漢字率 | 30.5% | **30.4%** | 27〜30% |
| 文の数 | 687 | 787（+14.6%） | — |
| 字数 | 41,499 | 42,598（+2.6%） | 減らさない |

文は分割された。しかし**漢字率はほぼ動かず、抽象語は抽象語のまま残った。**

読者にとっていちばん大きな障壁は、**文の長さではなく「何を言っているのか分からない」ことだった。**

### だから作業を2段階に分ける

**第1段階: 形式**
- 一文を 40〜50字に割る
- 漢字を開く
- 抽象名詞を動詞に戻す

これは機械的にできる。効果は測れる。**しかしこれだけでは読めるようにならない。**

**第2段階: 内容**
- 研究結果に「何をどう測ったか」を足す
- 抽象的な概念に「その場面が思い浮かぶ具体例」を足す
- 用語の説明を「それは何か」から「どう見えるか」に変える

**こちらが本体である。** そして機械的にはできない。素材を読み直す必要がある。

### 実務上の注意

**第1段階の指示と第2段階の指示を、同時にエージェントへ渡さないこと。**
実際に16章では、第2段階の規則を追加で送ったが、**届いた時点で第1段階が終わっており、
反映されなかった。** 2回に分けて走らせるのが確実である。

### 判断の目安

第2段階が終わったかどうかは、**字数で判断できる。**
具体例を足せば、必ず増える。**増えていなければ、足していない。**
16章の第1段階は +2.6% だった。第2段階では +10〜20% になるはずである。

## 測定の誤りと、方針の転換（2026-08-27）

### 検査スクリプトが一文の長さを過大に測っていた

11章の執筆者が指摘した。

> `check.mjs` の一文計測は、KeyPoints や Checklist の箇条書き末尾に句点がないと、
> 隣接する項目と連結してしまう。

そのとおりだった。**箇条書きの各項目を「1つの長い文」として数えていた。**
行の区切りも文の切れ目として扱うよう修正した。

### 修正後の実態

| | 修正前の測定 | 実際 |
|---|---|---|
| 03 あなたの条件で飼えるか | 39.4字 | **30.4字** |
| 14 トイレ・クレート | 39.0字 | **29.4字** |
| 01 人間に何が起きるか | 61.1字 | **34.9字** |
| 10 どこから迎えるか（未着手） | 68.6字 | **37.3字** |

**一文の長さは 25 / 29章がすでに目標圏内だった。**
超過は 04（56.1字）・09（50.4字・表中心）・21（52.7字）・25（54.9字）の4章のみ。

### 判明したこと

**文の長さは、実はほとんど問題ではなかった。**
最初にこの数字を見て「一文60〜102字」と判断し、形式の書き直しを優先したが、
その前提が測定の誤りだった。

**依頼者の指摘（「楽観的な判断のかたよりが具体的に何か分からない」）は、
最初から文の長さの話ではなかった。** 抽象的な記述が具体的でないことの指摘だった。

### 方針の転換（依頼者の判断）

**残りは第2段階（具体化）だけを適用する。**

- 一文を割る作業は不要（すでに目標圏内）
- 漢字を開く作業も、35%超の章で「開ける語だけ」に留める
  （医療・法律・お金の章は37%前後が現実的な下限。書き直し済みの29章が37.8%）
- **研究に測り方を足し、抽象語に場面を足す。これだけに集中する**

作業量は半分になり、効果は大きい。

### 教訓

**測る前に、測り方を疑う。**
数字が出ると、それを前提に方針を組み立ててしまう。
今回は執筆者が測定の欠陥に気づいたから修正できたが、
気づかなければ「文を割る」作業を29章に適用して、
本当の問題（具体性の欠如）に手が回らなかった可能性がある。

## 指示する側のミス: 素材にない語を指示に混ぜた（2026-08-27）

26章（認知症）の具体化を指示したとき、私（統括役）は例として
**「アミロイドβ = 脳にたまるタンパク質。人のアルツハイマー病でも同じものが見つかる」**
を挙げた。

しかし**この語は素材（`docs/research/12-longevity-cognitive-decline.md`）に一切登場しなかった。**

執筆者は書かなかった。報告にこうある。

> アミロイドβは素材に一切登場せず、WebSearch禁止のため追加していません

**正しい判断である。** 指示より原則（§15）が優先された。

### 教訓

**指示を書く側も、素材を確認してから例を挙げること。**
統括役が「こういう具体例を足せ」と書くと、執筆者はそれを正解だと受け取りやすい。
素材にない語を例示すると、**執筆者を原則違反に誘導することになる。**

今回は執筆者が踏みとどまったが、指示の書き方としては誤りだった。

同種のリスクがある箇所:
- 「〜のような具体例を」と書くとき、その具体例が素材にあるか確認する
- 確認できない場合は「**素材にあれば**」と条件を付ける（実際、他の指示ではそう書いていた）
