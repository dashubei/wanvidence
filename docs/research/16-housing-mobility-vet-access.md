# 住居・移動・病院アクセス——犬を前提に住む場所を決める

## この章の読み方

想定読者は住居が未定で、引っ越しの可能性がある。つまりこの章は「いま住んでいる場所で犬とどう暮らすか」ではなく、**「犬を前提にどこに住むかを決める」ための意思決定支援**として書く。

調査の結果、次の一点が本章の中核であることが裏付けられた。

> **深夜対応の救急動物病院までの距離と到達手段は、物件を選ぶ段階でしか取り返せない要因である。**

理由は単純で、以下のように事実が積み重なっている。
1. 犬の急変（胃拡張捻転症候群・誤飲・熱中症・痙攣重積・尿路閉塞など）は、猶予時間が数十分〜数時間単位しかないものが多い（後述の一覧表）。
2. 日本には人間の救急医療のような「救急告示病院」の法的な地域配置制度がなく、夜間対応可能な動物病院は民間の自主的な運営に委ねられている。分布は都市部に大きく偏っている（本章2-3）。
3. 深夜に犬を連れて移動できる手段は事実上「自家用車」か「電話で呼べるペットタクシー」のみで、一般のタクシー配車アプリの標準サービスはペット同乗を想定していない（本章3）。
4. これらはすべて「引っ越した後」ではなく「引っ越す前」に確認・準備しておかないと意味がない。

したがって本章の各節は、最終的に「犬を前提に物件を選ぶチェックリスト」（本章13）に集約される設計にした。

### 1-1　GDVの死亡率になぜこれほど幅があるか

同じGDVでも出典によって死亡率が「15%」から「68%」まで大きく異なる。本調査で確認できた範囲では、この幅は少なくとも次の要因の違いに起因すると考えられる（**ただし各出典が母集団の定義を明記していないケースが多く、正確な原因の切り分けは裏が取れていない**）。
- 「治療（手術）を受けた症例に限定した死亡率」か「治療の有無を問わない全症例」かの違い
- 症状出現から受診・手術までの時間（5時間超の遅延がある群では死亡率が明確に上がる）[^1]
- 腹膜炎・胃壁壊死・脾摘出の有無（合併症がある場合は45%以上という数字も）[^2]
- 調査年代・調査対象施設（一次診療 vs 二次診療施設）による違い

読者への実務的な含意は一貫している。**幅はあっても「時間が経つほど危険度が跳ね上がる」という方向性は全出典で一致**しており、「様子を見る」という選択肢の危うさを示す数字として扱ってよい。

## 2. 日本の夜間救急動物病院——分布・費用・かかりつけ医との関係

### 2-1　動物病院そのものの地域偏在

人間の医療と異なり、動物病院の開設に地域的な配置規制はない。農林水産省が毎年公表する「飼育動物診療施設の開設届出状況」によれば、令和5年時点で全国の動物病院（飼育動物診療施設）は16,825件、うち犬猫等の「小動物、その他」を扱う施設は12,706件とされる（令和3年12月31日時点の集計では12,102件という数字も見られ、年度や集計方法により数字が変動している）[^17][^18]。

農林水産省の資料そのもの（PDF）は本調査では直接開くことができなかった（アクセス制限）ため、この節の数字は検索エンジン経由で取得した要約に基づく**二次情報**である。正確な最新値は農林水産省の公式ページで確認することを推奨する[^17]。

分布の傾向について、農林水産省の資料を引用する複数の情報源が一致して次のように述べている。
- 小動物診療の獣医師・施設は、人口を反映して**関東・関西・中京圏など大都市圏に集中**している[^17]。
- 「小動物、その他」の施設数が500件を超えるのは埼玉・千葉・愛知・大阪・兵庫の各府県のみで、東京都・神奈川県が突出して多い[^18]。
- 首都圏から離れるほど動物病院の数は減少する傾向がある[^18]。

**「夜間救急動物病院」だけを対象にした全国規模の公的統計は、本調査では見つからなかった。** 存在するのは民間の検索サイト（例：全国夜間救急動物病院検索サイト[^16]）による任意登録ベースの一覧であり、これは人間の救急医療における「救急告示病院」制度（消防法に基づき都道府県が指定・公表する）とは性格が異なる。つまり、**「自分の生活圏に夜間救急動物病院が何件あるか」を確認する公的な一次データベースは存在せず、読者自身が個別に検索・電話確認するほかない**というのが実務上の結論になる。この点は本章のチェックリストに直結する（本章13）。

### 2-2　二次診療施設（紹介制の高度医療機関）

一次診療（普段のかかりつけ医）で対応できない疾患は、二次診療施設に紹介される仕組みが日本でも整いつつある。
- 日本動物高度医療センター（JARMeC）は川崎・東京・名古屋・大阪に拠点を持ち、CT・MRI・放射線治療装置を備えた紹介制の二次診療施設[^21]。
- 全国には二次診療専門とみられる動物病院が52件確認できる（動物病院口コミサイトの検索結果に基づく、厳密な定義や網羅性は不明）[^21]。
- 東京大学・日本大学・麻布大学など大学附属の動物医療センターも高度医療の受け皿になっている[^21]。
- 二次診療は基本的に完全予約制・紹介制であり、**飛び込みでの受診はできない**。つまり夜間の一次救急対応ができる病院とは役割が異なる。

二次診療施設も大都市圏（川崎・東京・名古屋・大阪など）に集中しており、地方在住者が高度医療を必要とする場合は長距離の移動が前提になる。

### 2-3　夜間救急の診療費——実額

夜間救急を利用した場合の費用感を、確認できた実例で示す（**個々の病院の料金は変更されうるため、あくまで相場観として読むこと**）。

| 項目 | 金額の目安 | 出典 |
|---|---|---|
| 通常診療時の初診料 | 1,000〜3,000円程度 | ペットドック[^49] |
| 夜間救急の初診料（例：名古屋夜間動物救急センター） | 8,000円（税別） | [^19] |
| 夜間の時間外料金（例：日本動物医療センター、20:00〜9:00） | 13,200円 | [^20] |
| 夜間診療の追加料金の相場感 | 通常診察料に加えて5,000〜10,000円程度が一般的 | [^20]系情報 |
| 夜間救急受診1回あたりの総額目安 | 2〜3万円以上を見込むべき。ショックや呼吸困難など重篤な場合は10,000〜50,000円程度 | 複数の夜間救急病院の料金公開情報の集約[^19][^20] |

**重要な注意点**：時間外診療費（時間外加算・深夜加算）は「診察料への加算」という性格上、ペット保険の補償対象外となるケースが多いとされる[^49]。保険に入っていても夜間救急の全額がカバーされるとは限らない点は、費用章（15章）とも関係するためここに明記しておく。

### 2-4　かかりつけ医の選び方——本章に関係する視点だけ

かかりつけ医選びの一般的な基準（相性・清潔さ・説明の分かりやすさ等）は他の章（予防医療・費用）に譲り、ここでは住居との関係に限定して述べる。
- かかりつけ医が**夜間・休日は診療していない**（多くの一次診療施設がそうである）場合、緊急時にどこの夜間救急に送られるかを事前に確認しておくべきである。多くのかかりつけ医は提携する夜間救急施設を案内できる。
- 「かかりつけ医は近いが、そこが休診の時間帯にはどこも近くにない」という状態は珍しくない。**かかりつけ医までの所要時間」と「夜間救急までの所要時間」は別々に確認する必要がある**（同じ病院とは限らない）。

### 2-5　住む場所を決めるときの判断基準（数値の目安）

本調査では「かかりつけ医まで何分、夜間救急まで何分が妥当か」を定めた学術研究・公的基準は見つからなかった。これは【裏が取れず】として明記する。したがって以下は、1章で示した猶予時間（特に痙攣重積の「30分以内の治療開始で反応率80%」、GDVの「5時間超の遅延がリスク因子」）から**逆算した実務的な目安**であり、公式な基準ではないことを断ったうえで提示する。

- **自家用車で夜間救急まで30分以内**を一つの目安にする。これは重積発作の「30分以内治療開始」という数字に対応させたものであり、実際には「異変に気づく→クレートに入れる→車を出す」までの準備時間も上乗せされる点を考慮する必要がある。
- 自家用車がない場合、深夜に呼べる移動手段（本章3）の到着時間も加算して見積もる。
- 夜間救急の存在だけでなく、**診療時間帯（22時までか、24時間対応か）と休診日**も物件検討時に確認する。夜間救急とうたっていても曜日限定・要事前連絡制の施設もある。
- 検討中の物件の住所を起点に、実際に地図アプリで「深夜0時に自動車でこの病院まで何分か」をシミュレーションしてから内見に行くことを推奨する（渋滞のない深夜想定でも、山間部・郊外では想像以上に時間がかかることがある）。

## 3. 深夜に動物病院へ行く手段——実務検証

「深夜に本当にタクシーを呼べるのか」という問いに答えるため、主要な移動手段を個別に検証する。**結論を先に言うと、深夜の確実な移動手段として現時点で最も信頼できるのは自家用車であり、タクシー・配車アプリは「使えないことがある」という前提で備える必要がある。**

### 3-1　自家用車

- クレート等に犬を収容し、シートベルト等で固定するのが基本（詳細は4-1）。
- 自家用車がある場合、深夜でも移動手段として最も確実。ただし運転者自身が動揺・寝不足の状態で運転することになるリスクは無視できない。
- 自家用車を持たない場合、レンタカー・カーシェアは深夜の緊急時に**その場で借りられるとは限らない**（無人ステーションのカーシェアは可能な場合があるが、事前会員登録が必須）。「いざという時にレンタカーで」という想定は、事前に会員登録を済ませていない限り機能しない。

### 3-2　タクシー（一般）

- 法的には、ペットは「手荷物」として扱われ、飼い主が同乗する限りタクシーに乗せること自体は可能とされる（旅客自動車運送事業運輸規則第52条の解釈）[^37][^38]。
- ただし、**配車を依頼する時点でペット同乗の意思を運転手・オペレーターに伝える必要がある**。これを怠ると乗車拒否につながりうる[^37]。
- 大手タクシー会社の中には公式サイトで「ペット同乗可」と明記している例もあるが、これは**会社としての方針であって、個々の運転手・車両が必ず対応するとは限らない**（動物アレルギーのある運転手や、次の乗客への配慮から断られるケースが実務上ありうる。この点は個別の運転手判断に委ねられる部分があり、確実性を保証するものではない）。
- 配車アプリ「GO」の標準サービス（GOエコノミー）は、公式に**動物の持ち込みを想定していない**（「危険物、動物、不潔なもの、臭気を発するものなど、他のお客様にご迷惑となるおそれのあるものは持ち込みできません」と明記）[^38]。つまり、深夜に思い立ってGOアプリで呼んだタクシーに犬を乗せられる保証はない。
- DiDiなど他の配車アプリについても、公式にペット同乗を保証する記載は本調査では確認できなかった[^37]。

**結論**：一般のタクシー・配車アプリは「乗せてもらえる可能性はあるが、確約されたサービスではない」というのが実態である。緊急時に確実性を求めるなら、後述のペットタクシーの連絡先を事前に控えておくか、自家用車を確保しておく必要がある。

### 3-3　ペットタクシー

- ペット輸送を専門に行う「ペットタクシー」は都市部を中心に多数存在する。
- 一部業者は24時間対応をうたっているが、**「事前予約」を前提としたものが多く**、深夜に突発的な依頼をした場合に即座に配車できるとは限らない[^39]。
- 深夜（0時〜6時）の利用には深夜料金が加算される業者が一般的[^39]。
- 地方では、そもそもペットタクシー自体が存在しない、または営業エリア外になる可能性が高い。ペットタクシーの充実度も都市部と地方で大きな差があると考えられる（**ただし全国のペットタクシー分布を定量的に示す統計は確認できなかった**【裏が取れず】）。

**実務上の推奨**：引っ越し先を検討する段階で、(1) 自宅から夜間救急までの距離、(2) 自家用車の有無、(3) 地域のペットタクシーの有無と24時間対応の可否・深夜料金、の3点をセットで確認し、**「自家用車がない場合の深夜の移動手段」を具体的な連絡先レベルで用意しておく**ことを勧める。

## 4. 移動手段（平時）

### 4-1　自家用車

**クレートの固定と法的位置づけ**

- 運転中に犬が自由に動ける状態は、ハンドル操作や視界を妨げる行為として道路交通法第55条2項（乗車又は積載の方法）に抵触しうるとされる[^40]。ただし本調査では e-Gov法令検索から条文本文を直接確認することができなかった（サイトの技術的制約により本文抽出に失敗）。**条文の正確な文言は読者自身が e-Gov法令検索で道路交通法第55条を確認することを推奨する**[^40]。
- 違反時の反則金は普通車で約6,000円、中・大型車で約7,000円、違反点数1点、という情報が複数の情報源で一致している[^40]。ただしこれも一次情報（警察庁・都道府県警発表の反則金一覧）では確認できておらず、二次情報止まりである。
- 実務的な推奨: クレートまたはケージに入れ、シートベルトや専用の固定具で固定する。膝の上に乗せる・窓から顔を出させる・車内を自由に歩き回らせるのはNG行為として広く指摘されている[^36]。

**車内温度上昇の実測データ**（駐車中に犬を残すことの危険性）

これは「散歩中の事故」ではなく「ちょっとの間だから」という判断の危うさを示す数字として重要。

| 条件 | 結果 | 出典 |
|---|---|---|
| 真夏、黒色車両、窓を閉め切り、エンジン停止 | 30分後に車内約45℃、15時頃には55℃超 | JAF系情報[^26] |
| 最高気温23℃（比較的過ごしやすい晴天） | 車内温度48.7℃、ダッシュボード付近70.8℃ | JAF系情報[^26] |
| エアコンを切って25℃の車内にドアを閉めて放置 | 5分後に約38℃（+10℃）、1時間後には50℃超 | 各種情報源の集約[^28] |
| 気温35℃の猛暑日 | 車内温度が70℃を超えることもある | [^28] |

サンシェードや窓を少し開ける等の対策も、JAFの検証では効果が限定的（対策ありでも車内平均温度40℃程度）とされている[^26]。**「エンジンを切って数分でも車内に犬だけを残さない」が唯一の確実な対策**という結論になる。

**レンタカー・カーシェアのペット規定**

本調査では大手レンタカー各社・カーシェア各社の個別のペット同乗規定（ケージ必須か、追加清掃料の有無等）まで一次情報で確認する時間的余裕がなかった。**多くのレンタカー会社はペットをそのまま車内に乗せることを想定しておらず、ケージ使用や追加クリーニング料が発生する場合がある**という一般的傾向は複数の周辺情報から推測されるが、各社の正確な規定は「利用する会社の公式サイトで事前に確認する」ことを読者に強く推奨する【裏が取れず・各社確認必須】。

### 4-2　鉄道

**必ず各社の現行規定を公式サイトで確認すること。以下は2026年8月時点で確認できた内容。**

JR東日本・JR東海（新幹線含む）[^31][^32]:
- 小犬・猫・鳩等の小動物は、全身が収まるペット用ケース・リュック等に入れ、顔や体の一部を出さない状態でのみ持ち込み可能。
- ケースは**縦・横・高さの合計120cm以内**、ケースと動物を合わせた重量**10kg以内**。
- 「手回り品きっぷ」が必要で、料金は**1個につき290円**。
- 抱っこ・リードのみでの乗車、カートから顔を出した状態での乗車は不可。
- 身体障害者補助犬法に定める盲導犬・介助犬・聴導犬（法定の表示がある場合）は、使用者本人が随伴する場合、ケース収納・手回り品きっぷ購入ともに不要。
- **大型犬は、体重・ケースサイズの上限を超えるため事実上新幹線・在来線には持ち込めない**。

私鉄（小田急電鉄・京王電鉄の例）[^33]:
- 小田急電鉄：長さ70cm以内、縦・横・高さの合計120cm程度以内。
- 京王電鉄：長さ70cm以内、縦・横・高さの合計90cm以内（JRより厳しい）。
- 東京メトロ・小田急・東急など多くの私鉄でペット持ち込み自体の追加料金は無料、という情報があるが、各社で扱いが異なるため必ず個別に確認すること。

**実務上の含意**：鉄道は小型犬〜中型犬の一部までが対象で、中〜大型犬は事実上利用できない。引っ越し先の検討時に「電車で犬を連れて移動する」ことを想定している場合は、犬のサイズと各社のケースサイズ規定を照らし合わせる必要がある。

### 4-3　バス

本調査では路線バス事業者のペット持ち込み規定について、大手複数社を横断的に一次確認する時間的余裕がなかった。一般に鉄道と同様に「ケースに入れて顔を出さない」形での持ち込みを条件とする事業者が多いと見られるが、**事業者ごとの差が大きいため、利用予定のバス会社公式サイトで個別に確認することを推奨する**【裏が取れず・各社確認必須】。

### 4-4　飛行機

**必ず各社の現行規定を搭乗前に公式サイトで確認すること。以下は2026年8月時点で確認できた内容。**

ANA（国内線）[^34]:
- 短頭種（鼻の短い犬種）は、暑さに弱く熱中症・呼吸困難のリスクがあるため、**毎年5月1日〜10月31日の夏季期間は預かりを中止**。
- 対象犬種として、ブルドッグ、フレンチ・ブルドッグ、ボクサー、シーズー、ボストン・テリア、ブル・テリア、キャバリア・キング・チャールズ・スパニエル、チベタン・スパニエル、ブリュッセル・グリフォン、チャウチャウ、パグ、チン、ペキニーズが挙げられている。

JAL（国内線）[^35][^36]:
- **フレンチ・ブルドッグとブルドッグ（およびこれらの雑種）は年間を通じて預け入れ不可**。
- パグ・チンなど他の短頭種は、通常時期であれば預け入れ可能。
- ただし国内貨物では、対象**21犬種**について夏季期間（毎年5月1日〜10月31日）は預かりを中止するという情報がある（この21犬種のリストの詳細は、JALカーゴの該当ページへの直接アクセスができなかったため本調査では確定できていない。搭乗・輸送前に必ずJAL公式ページで最新のリストを確認すること）[^36]。
- いずれの航空会社も、犬などの小動物を**客室内には持ち込めず、貨物室に預ける扱い**が基本（盲導犬等の補助犬を除く）。

**なぜ短頭種が制限されるか**：短頭種は鼻腔・気道の構造上、パンティング（喘ぎ呼吸）による体温調節の効率が低く、暑熱環境下での熱中症リスクが著しく高いことが背景にある。実際に短頭種が輸送中の熱中症で死亡した事故も報告されている[^35]。

**実務上の含意**：短頭種（フレンチ・ブルドッグ、ブルドッグ、パグ等）を飼う予定がある、または既に飼っている場合、飛行機での長距離移動（帰省・引っ越し）は季節によって選択肢が閉ざされることを前提に計画する必要がある。

## 5. 散歩コースの条件——アスファルトの路面温度と火傷リスク

**実測データ**[^24][^25]:

| 気温 | アスファルト表面温度の実測値 |
|---|---|
| 25℃ | 約52℃ |
| 30℃ | 約57℃ |
| 31〜32℃ | 約62℃（マンホールでは62℃という実測例も） |

**犬の肉球への影響**[^25]:
- 地面温度が**50℃**になると、肉球の発赤・炎症が起こりうる。
- **55℃を超えると、わずか1分程度の接触でも火傷のリスク**がある。
- 犬の肉球は人間の足裏の皮膚より熱に弱く、細かい血管の発達が乏しいため熱がこもりやすい構造とされる。

**安全な散歩時間帯の目安**：関東地方の真夏であれば、早朝5:30以前、または夜20:00以降が目安とされる[^24]。日本気象株式会社は路面温度を予測する「犬のおさんぽ予報」というサービスを提供しており、こうした予報サービスの活用も実務的な選択肢になる[^24]。

**簡易な確認方法として広く紹介されているのは「素手または素足の甲を5〜7秒アスファルトに当てて熱くて耐えられないなら、犬にとっても危険」という目安**である。これは体系的な実験研究というより実務的な経験則であり、エビデンスとしては【弱】だが、内見・散歩コース検討の際にその場で使える具体的な確認手段として有用なため、チェックリストに採用する。

**住居選びとの関係**：散歩コースの路面がアスファルト中心か、公園・河川敷など土や芝の区間があるかは、夏季の散歩の実行可能性に直結する。物件検討時に、実際に日中の散歩ルートを想定して確認することを推奨する。

## 6. 温度管理

### 6-1　室内の適正温度とエアコン運用

- 犬が快適に過ごせる室温の目安は25〜26℃程度とされるが、犬種・年齢・体格により異なる。暑さに弱い犬種では20〜22℃、比較的暑さに強い犬種では23〜26℃程度が目安として紹介されている[^47]。
- 留守番時にエアコンをつけっぱなしにする飼い主が多いという情報があるが、**この調査の元になった一次データ（調査主体・サンプルサイズ・調査年）は本調査では特定できなかった**【裏が取れず】。傾向としては妥当と考えられるものの、数値の出典としては採用しない。

### 6-2　エアコンの通年運転コスト（実額）

- エアコン使用時の電気代は1日あたり約77円、**月額2,000〜3,000円程度**が目安として複数の情報源で一致している[^48]。
- ただしこれは機種・設定温度・住宅の断熱性能・電力単価によって大きく変動するため、あくまで目安である。
- 遮光カーテンの併用や、電力会社のペット向け割引プランの活用が節約策として紹介されている[^48]。

**住居選びとの関係**：断熱性能の低い物件（古い木造アパート、単板ガラスの窓等）では、同じ設定温度でも電気代がかさむ可能性が高い。物件の断熱等級・築年数・窓の仕様は、犬を通年で留守番させる前提であれば経済的にも無視できない要素になる。

### 6-3　停電時の対策

- 冷却マット、保冷剤・凍らせたペットボトルの活用、遮光・通風の確保、こまめな水分補給が基本的な対策として挙げられている[^29][^30]。
- 凍らせたペットボトルを扇風機の前に置くことで簡易的な冷却効果が得られるという方法も紹介されている[^29]。
- 断水時に備え、食料・水は最低3日〜1週間分の備蓄が推奨されている[^29]（これは災害備蓄の一般的な推奨と重なる。本章11も参照）。

### 6-4　熱中症の発生データ（月別・時間帯別・場所別）

**月別データ**（アニコム損保「どうぶつ健保」契約データ、2012年）[^13]:
- 最高気温が25℃を超える夏日が観測され始める**5月から熱中症の保険金請求が急増**。
- 別の情報源では、5月は4月と比較して熱中症が4倍に急増するとも報告されている。
- ピークは8月。9月には件数が減少する傾向。
- **この2012年データはやや古く、直近年のデータでの再確認が望ましい**【中・データがやや古い】。

**時間帯データ**（アニコム損保、2021年7月21日〜8月11日実施のWEBアンケート、2019・20年度に熱中症で保険金請求歴のある飼い主が対象、有効回答数**37件**）[^14]:
- 発生時間帯は「昼過ぎ（12〜15時）」が最多。
- **サンプルサイズが37件と小さいため、全国的な傾向として一般化するには注意が必要**【弱・n=37】。

**発生場所データ**[^14][^15]:
- 「散歩中・ドッグラン」と「自宅内（リビング等）」の両方で発生が多く、**屋外だけでなく屋内でも約半数程度が発生している**という情報がある。つまり、「室内にいれば安全」という思い込みは誤り。
- 車内での発生リスクについても複数の情報源が言及している（本章4-1のデータを参照）。

**リスクの高い犬種**[^13]:
- 短頭種（シーズー、パグ、フレンチ・ブルドッグ、ボストンテリア等）：パンティングによる体温調節が構造的に苦手。
- 寒冷地原産犬種（シベリアン・ハスキー、サモエド、グレート・ピレニーズ、オールド・イングリッシュ・シープドッグ等）：厚い被毛が日本の高温多湿環境で不利に働く。

**日本全体の熱中症死亡率**：ある情報源では「熱中症全体の死亡率は約14%だが、動物病院に緊急搬送された症例の死亡率は約50%」という数字が示されている[^15]。この「14%」と「50%」は分母（全熱中症疑い例か、搬送された重症例か）が異なると考えられるが、**元の一次データ（調査主体・症例数）を本調査では特定できなかった**ため、参考値としての扱いにとどめる【弱】。

## 7. 住居形態別の課題とペット可賃貸の実態

### 7-1　住居形態別マトリクス（概観）

| 住居形態 | 主な課題 | 主な利点 |
|---|---|---|
| 賃貸マンション・アパート | ペット可物件自体が少数派。家賃・敷金の上乗せ。管理規約による体重・頭数制限。退去時の原状回復費用リスク | 引っ越しの柔軟性が高い（住居未定の想定読者には親和性が高い） |
| 分譲マンション | 管理規約次第（規約でペット飼育自体を禁止している場合や、体重・種類を制限している場合がある）。共用部（エレベーター・廊下）での抱っこ・カート移動の義務付けが一般的[^50][^51] | 賃貸のような貸主都合の退去リスクがない |
| 戸建て（持ち家） | 庭の管理（フェンス・有毒植物・脱走防止）が自己責任。防音は集合住宅より有利 | 鳴き声トラブルのリスクが相対的に低い。庭での排泄・運動がしやすい |
| 戸建て（賃貸） | 供給数が少ない。ペット可の条件は家主判断でばらつきが大きい | マンションより騒音制約が少ない場合が多い |

### 7-2　ペット可賃貸の実態データ

**割合**：不動産ポータルサイトの掲載物件ベースで、ペット相談可・ペット可物件の割合は増加傾向にある[^29]。
- LIFULL HOME'S掲載物件：2022年3月時点で12.9%→ 2025年3月時点で19.3%。
- SUUMO掲載物件：2019年1月時点で10% → 2024年1月時点で18%。

**注意点**：これは「全賃貸住宅ストックに占める割合」ではなく「特定ポータルサイトの掲載物件に占める割合」である点に留意が必要。実際の市場全体の割合とは異なる可能性がある【中・ポータル掲載ベースの数字であることに注意】。

**家賃の上乗せ**：月額数千円〜1万円程度、または家賃の10〜30%程度が上乗せされるという情報が複数ある[^30]。別の調査では「ペット可物件はペット不可物件より平均家賃が3万円以上高い」とも報告されているが、これは**物件の築年数・立地・設備等の違いによる交絡の可能性があり、純粋な「ペット可であること」の価格効果とは限らない**点に注意が必要【弱・交絡の可能性を排除できていない】。

**敷金の上乗せ**：ペットによる損耗を見込んで、敷金が家賃1ヶ月分程度上乗せされることが多いとされる（1〜2ヶ月分の追加という情報もある）[^30]。

**多い制限**：
- 体重制限（小型犬までとする物件が多いとされるが、全国的な分布を示す定量データは確認できなかった）
- 頭数制限（1〜2頭まで等）
- 大型犬・特定犬種の除外
- 共用部での抱っこ・カート移動の義務化[^50][^51]

**退去時の原状回復費用の実態**：ペット飼育を伴う退去時の原状回復費用は、1Kクラスで5万〜30万円程度が目安とされるが、フローリングの全面張替え等が必要と判断された場合は50万円、事例によっては100万円超が請求されたケースも報告されている（後者は交渉により30万円以下に減額された例もある）[^47]。裁判例としては、12年間居住・爪痕や糞尿による床の損傷があったケースで、借主の負担割合を30%と判断した例が紹介されている[^47]（詳細な原状回復ガイドラインとの関係は14章「法令・条例」を参照）。

## 8. 階数・エレベーター・床材

### 8-1　階数とエレベーター

- 多くのペット可マンションでは、エレベーター・共用廊下・エントランスなど共用部を犬に**直接歩かせることを禁止**し、抱っこまたはキャリーバッグ・カートでの移動を義務付けている[^50][^51]。
- 「ペットボタン」付きエレベーターを備える物件もあり、ペット同乗を知らせて他の住民が乗り合わせを避けられるようにする配慮がなされている場合がある[^51]。
- 大型犬の場合、「抱っこできるサイズまで」という規約を設けているマンションもあり、体格によっては入居自体を断られる可能性がある[^51]。**大型犬を検討している場合は、内見前の問い合わせ段階で共用部のルールと体重上限を確認すべき**。
- 高層階の場合、エレベーター故障・点検中の階段移動が大型犬・老犬には負担になりうる（特に緊急時に病院へ運ぶ場面を想定すると、低層階または明確な代替動線があることが望ましい）。

### 8-2　床材と関節疾患の関連——本調査における最重要の「裏が取れなかった」点

これは団体からの依頼で特に数値を求められた項目だが、**明確に断っておく必要がある**。

- フローリング等の滑りやすい床材が、股関節形成不全や前十字靭帯断裂のリスクを高めるという説明は、犬関連の商業サイト（フロアコーティング業者、ペット用品店等）に**極めて広く**見られる[^23]。
- そのメカニズムとして語られるのは、「滑らないよう踏ん張ることで関節に不自然な負荷がかかる」「滑って転倒することで靭帯を損傷する」というものである[^23]。
- しかし、本調査で英語・日本語の両方で学術文献（PubMed、JAVMA等）を検索した範囲では、**「床材の種類・滑りやすさ」を独立したリスク因子として定量的に評価した査読付き疫学研究は見つからなかった**。
- 股関節形成不全・前十字靭帯断裂の疫学研究で確認された危険因子は、犬種、体重、去勢・避妊の有無と時期、年齢、体重/体高比などであり[^22]、「床材」を扱った研究は本調査の範囲では確認できなかった。
- JAVMA掲載の大規模観察研究（Witsberger et al., 2008、*J Am Vet Med Assoc* 232(12)）は、去勢雄・避妊雌で股関節形成不全・前十字靭帯断裂のリスクが有意に高いこと、4歳以下では股関節形成不全が、4歳超では前十字靭帯断裂がそれぞれ多い傾向を報告しているが、床材には言及していない[^22]。

**結論として本章に書けること**：
1. 「滑りやすい床が関節に良くない」という**説明のメカニズム自体は整形外科学的に不合理ではない**（急停止・急旋回時の関節への負荷は一般に問題視される）。
2. しかし、これを**定量的なリスク因子として実証した疫学研究は確認できなかった**。したがって「フローリングだと股関節形成不全になる確率が何%上がる」といった数値は、本調査では一切裏付けが取れていない。
3. 対策（滑り止めコーティング、タイルカーペット等）についても、その**効果を定量的に検証した研究は確認できなかった**。業者の販促サイト以外に費用対効果を扱った独立した情報源は見つからなかった。
4. したがって本章では、床材対策を「エビデンスに基づく予防」としてではなく、**「機序として合理的だが、効果量は未検証の一般的な生活環境整備」**として位置づけるべきである【弱・機序からの推論、直接の疫学研究なし】。

**費用感（参考、業者サイトベース）**：滑り止めのフロアコーティングは数十万円規模の施工費がかかる場合があり、タイルカーペット・コルクマット等の後付け対策は数千円〜数万円で部分的に導入できる。ただしこれらの価格情報も出典が業者サイトに限られ、独立した比較調査は確認できていない【裏が取れず】。

## 9. 騒音

- 犬の吠え声の音量は概ね**90〜100dB**程度、小型犬でも60〜80dB程度とされる[^46]。
- 環境省の定める騒音に係る環境基準（一般的な住居専用地域）では、**昼間55dB以下・夜間45dB以下**が目安とされており、犬の吠え声はこれを大きく上回る[^46]。
- 防音対策として、床（防振マット・足音マット等の多層化）、窓（防音カーテン・防音ボード）、壁（吸音パネル）の対策が紹介されているが[^46]、**それぞれの対策による具体的な減音効果（dB単位での改善量）を定量的に示した独立検証は確認できなかった**【弱・効果量不明、業者サイト情報が中心】。
- 集合住宅での鳴き声トラブルの法的位置づけ（受忍限度論、判例）については14章「法令・条例」、吠えの原因別対処については07章「吠え」を参照。本章では住居選びの観点からのみ扱う。

**住居選びとの関係**：内見時に、隣室との壁の厚さ（コンクリート造か軽量鉄骨か木造か）、上下階との音の伝わりやすさを確認することが実務的な対策になる。鉄筋コンクリート造（RC造）は木造・軽量鉄骨造より遮音性能が高い傾向にあるとされるが、これも建物の構造・築年数により差が大きい。

## 10. 間取り・脱走防止・誤飲防止・有毒植物

### 10-1　脱走防止・誤飲防止の環境設計

一般的に推奨される対策（複数の情報源で共通して言及されているが、個別に効果検証された研究があるわけではなく、実務的なチェックリストとして扱う）:
- 玄関・ベランダの二重扉化、または柵の設置
- 網戸のロック強化（前脚で押し開けられることがある）
- ベランダの手すりの隙間（小型犬・子犬がすり抜けられる隙間がないか）
- 誤飲しやすい小物（靴下、輪ゴム、電池、薬等）を床に置かない収納習慣

### 10-2　庭のフェンス高

本調査では、犬種別に必要なフェンス高を定量的に示した公的基準・学術研究は見つからなかった【裏が取れず】。実務記事では「中型犬で1.2m以上、ジャンプ力のある犬種はより高く」という目安が語られることが多いが、出典として確度の高いものは特定できなかった。

### 10-3　有毒植物

犬にとって危険とされる代表的な植物と、確認できた注意点は以下の通り[^45]。

| 植物 | 危険性 |
|---|---|
| ユリ（百合） | 強い毒性。花びらを舐める、花瓶の水を飲むだけでも危険とされる（**猫での毒性の方がより深刻とされるが、犬でも注意喚起の対象**） |
| アジサイ | シアン化合物を含み、嘔吐・下痢・口内炎等を引き起こしうる |
| スズラン | コンバラトキシンを含む。接触するだけでも影響が出る場合があるとされる |
| 朝顔（アサガオ）の種 | 有毒。嘔吐・下痢を引き起こしうる |
| アロエ | 嘔吐・下痢等の中毒症状 |
| ポトス | シュウ酸カルシウムを含み、口腔内の刺激・腫れを引き起こしうる |
| スイセンの球根 | アルカロイド（リコリン等）による中毒 |

対策として、鉢植えを犬の届かない高さに置く、庭の花壇に柵を設ける、危険な植物がある部屋に犬を入れないといった方法が紹介されている[^45]。**誤食してしまった場合は、自己判断で様子を見ず速やかに動物病院（夜間の場合は夜間救急）に連絡することが推奨される**（本章1の「誤飲・中毒」の猶予時間を参照）。

## 11. 災害への備え

### 11-1　同行避難ガイドラインの位置づけ

環境省は「災害時におけるペットの救護対策ガイドライン」（平成25年6月策定、その後改訂）で、**飼い主の責任による「同行避難」**を原則として打ち出している[^41]。

重要な点として、このガイドラインには**法的な強制力がない**。環境省ガイドラインはあくまで自治体が地域の防災計画・マニュアルを作る際の参考資料という位置づけであり、避難所でのペット受け入れ方針は自治体ごと・避難所ごとにばらつきがある[^41][^43]。

### 11-2　同行避難の実態（熊本地震の事例）

平成28年（2016年）熊本地震では、多くの飼い主が同行避難を行ったことが報告されている一方で[^42]:
- 避難所がペット受け入れ不可であったため、危険な自宅に引き返した事例
- 飼い主とペットが避難所ではなく車中泊を選んだ事例

が多数報告されている[^42]。「同行避難」という言葉が「避難所でペットと一緒に過ごせる（同伴避難）」ことを意味すると誤解されがちだが、**実際には「避難所まで一緒に連れて行く」ことを指すに過ぎず、避難所内でペットと同じスペースで過ごせるかどうかは別問題**である点は、読者に正確に伝えるべき重要な区別である。

### 11-3　備蓄品の目安

複数の情報源で共通して挙げられている備蓄品は以下の通り[^29][^41]:
- 水・フード（最低3日分〜1週間分を推奨する情報源が多い）
- 常備薬（持病がある場合）
- キャリーバッグ・ケージ（避難所での指定される可能性が高いため、平時から慣らしておくことが推奨される）
- 首輪・リード（予備を含む）、迷子札
- 排泄物処理用品

### 11-4　迷子対策・マイクロチップ

- 2022年6月の動物愛護管理法改正により、犬猫販売業者にはマイクロチップの装着・登録が義務化された（詳細は14章「法令・条例」参照）。
- 引っ越し・住所変更時は、環境省の「犬と猫のマイクロチップ情報登録」サイト（reg.mc.env.go.jp）でオンライン手続きが可能[^44]。手続きには登録証明書記載の識別番号と暗証記号が必要。
- コールセンター（03-6384-5320、平日・土曜9:00〜18:00、日祝年始除く）でも対応可能[^44]。
- 2022年に始まった「狂犬病予防法の特例制度」により、特例対象の自治体ではマイクロチップの情報変更が狂犬病予防法上の住所変更届と兼ねられるようになった（自治体差があるため、転居先の自治体が特例対象かどうかは個別確認が必要）[^44]。

### 11-5　将来の引っ越しを見据えた注意点

災害時の同行避難だけでなく、通常の引っ越し自体が犬にとってストレス要因になりうる。確認できた実務的な知見は以下の通り（**いずれも体系的な研究ではなく実務記事レベルの情報**【体験・弱】）。
- 生活環境の急激な変化により、トイレの失敗、無駄吠えの増加、食欲低下、下痢・嘔吐などの体調不良が起こりうるとされる[^29]。
- 旧居で使っていた匂いのついた寝具・タオル等を新居に持ち込むと安心材料になるという説明が広く見られる[^29]。
- 新居では長時間の留守番をいきなりさせず、徐々に一人の時間を延ばしていく段階的な慣らしが推奨されている[^29]（分離不安の予防プロトコルは07章「吠え」も参照）。
- 引っ越し当日は自家用車や使い慣れたキャリーでの移動、移動時間の短縮が推奨される[^29]。
- 長期休暇（ゴールデンウィーク・お盆等）に合わせて引っ越すことで、新居に慣れる時間を確保しやすいという助言が複数の情報源で共通して見られる[^29]。

**物件の探し方に関する実務上の注意**：物件のペット可否・体重制限・頭数制限は掲載情報と実際の管理規約で食い違うことがあるため、内見・契約前に「管理規約の該当条項」を書面で確認することが望ましい（口頭説明だけに依拠しない）。また、動物病院・かかりつけ医の変更（転院）は、可能であれば転居前に新しいかかりつけ医の候補を決めておくと、緊急時の空白期間を短縮できる。

## 12. 「犬を前提に物件を選ぶチェックリスト」

以下は本章の調査全体から導いた、**内見時にその場で確認できる粒度**のチェックリストである。`<Checklist>` コンポーネントでの実装を想定し、項目を分割してある。

### A. 病院アクセス（最優先——内見前に済ませておく）
- [ ] 物件の住所から半径5km圏内に、夜間対応（できれば24時間対応）の動物病院があるか、地図アプリ・検索サイトで確認した
- [ ] 見つけた夜間救急病院に**実際に電話し**、対応時間帯・休診日・予約要否を確認した
- [ ] 深夜0時を想定して、自動車での所要時間を地図アプリでシミュレーションした（目安：30分以内が望ましい）
- [ ] かかりつけ医の候補を最低1件、物件から30分圏内で決めた（夜間救急とは別施設でよい）
- [ ] 自家用車がない場合、地域のペットタクシー業者を最低1件見つけ、深夜対応の可否・予約要否・深夜料金を確認した
- [ ] 二次診療施設（専門的な手術等が必要な場合の紹介先）が現実的な距離にあるか確認した（都市部以外では長距離移動が前提になりうる）

### B. 契約条件
- [ ] ペット可の条件が「小型犬まで」等の体重制限を伴っていないか、管理規約の該当条項を書面で確認した
- [ ] 頭数制限の有無を確認した（将来2頭目を検討する可能性があるか自問した）
- [ ] 家賃・敷金の上乗せ額を確認し、総額で比較した
- [ ] 退去時の原状回復費用の想定（クロス・フローリングの扱い）について、契約書の特約条項を確認した

### C. 共用部・構造
- [ ] エレベーター・廊下・エントランスでの犬の移動ルール（抱っこ必須か等）を確認した
- [ ] 検討している犬種・サイズが「抱っこできるサイズ」の規約に抵触しないか確認した
- [ ] 隣室・上下階との壁・床の構造（RC造か木造か）を確認した
- [ ] エレベーターが停止した場合の階段移動が現実的か（大型犬・将来の老犬期を想定）確認した

### D. 温度・床材
- [ ] 主要な生活動線（リビング・寝室）の床材が滑りやすい素材か確認した
- [ ] 部屋の断熱性能（築年数、窓がペアガラスか単板か）を確認し、通年エアコン運転を想定した電気代を見積もった
- [ ] 日当たり・西日の入り方を確認し、夏季の室温上昇リスクを見積もった

### E. 周辺環境
- [ ] 実際の散歩ルートを歩き、アスファルト中心か、土・芝の区間があるか確認した
- [ ] 真夏の日中を想定し、素手の甲を地面に当てて熱さを確認する等の方法で路面温度リスクを体感した
- [ ] ドッグラン・公園までの距離を確認した
- [ ] 庭がある場合、フェンスの高さ・隙間、有毒植物の有無を確認した

### F. 災害・緊急時
- [ ] 指定避難所がペットの同行避難を受け入れているか、自治体の防災計画を確認した
- [ ] 停電時の暑さ対策（風通し、日当たり）を物件の構造から確認した
- [ ] 転居後にマイクロチップの登録住所変更が必要になることを覚えておく

## 13. 統合サマリー——章の結論

1. **夜間救急動物病院への距離・到達手段は、事前確認と物件選びでしか担保できない。** 猶予時間が数十分〜数時間しかない緊急事態（GDV・熱中症・重積発作・尿路閉塞等）が複数存在する以上、「引っ越してから調べる」では手遅れになりうる。
2. **深夜のタクシー配車は確約された移動手段ではない。** 標準的な配車アプリ（GO等）は動物の持ち込みを想定しておらず、確実性を求めるなら自家用車の確保か、ペットタクシー業者への事前連絡先確保が必要。
3. **日本には「夜間救急動物病院」を網羅する公的データベースが存在しない。** 読者自身が転居予定地域で個別に検索・電話確認する以外に方法がない。
4. **床材と関節疾患の関連は、機序としては合理的だが、疫学研究による定量的な裏付けは本調査では確認できなかった。** 対策自体を否定する根拠もないが、「フローリングは危険」という断定的な言い方は現時点のエビデンスでは正当化できない。
5. アスファルトの路面温度・車内温度上昇には明確な実測データがあり、行動レベルの対策（散歩時間帯の調整、車内放置の絶対的な回避）に直結する。
6. ペット可賃貸は市場全体で増加傾向にあるが、家賃・敷金の上乗せ、体重・頭数制限、退去時の原状回復費用リスクは無視できない実額として存在する。
