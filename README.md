# 🐕 Wanvidence

出典のない主張は書かない、犬と暮らすための29章。

**https://dashubei.github.io/wanvidence/**

## これは何か

これから初めて犬を飼う人のための本です。
研究で確かめられていることと、実際に飼っている人が語っていることを、混ぜずに並べました。
どの主張がどれくらい確かなのかが、文ごとに分かるようにしてあります。

全29章・8部構成、約47万字。本文は日本語のみです。全文検索が付いています。

章は、犬の生物学からではなく「そもそも飼えるのか」から始まります。
読む人が判断を迫られる順に並べてあるからです。
各章は3つの層に分かれています。急いでいる人は先頭の結論だけ読めば行動できます。
標準の読者は本文を読みます。研究の中身・数値・サンプルサイズ・その研究の限界は、
折りたたみの中に入れてあります。

主張の直後には、根拠の強さがバッジで出ます。5段階です
（強い根拠・中程度の根拠・弱い根拠・体験談・論争中）。

守っている原則は5つです。

1. **出典が確認できない主張は書かない。**
   裏が取れなかったものは、消さずに「確認できなかった」と本文に書きます
2. **体験談と科学的根拠を視覚的に分離する。**
   体験談は `<Experience>` の枠の中だけに置き、本文に溶かしません
3. **論争があるものは、論争があると書く。**
   `<Disputed>` で、日本で一般的に行われていることと、国際的な学会が推奨していることを
   左右に並べます
4. **リスクを書いたら、その隣に必ず対処法を置く。**
   リスクだけを見せられた人は、回避するだけで行動は変わらないと分かっています
5. **「重要である」で終わる文を書かない。**
   数値・手順・時間・失敗例のどれかまで落とします

専門用語は消しません。初出のときに日常語の言い換えを添えます。
獣医師やトレーナーに相談するとき、正しい語を知っていること自体が役に立つからです。

付録の3つ（論争のあるトピック・用語集・出典一覧）は、本文から自動生成しています。

## 誰のための本か

**日本に住む、これから初めて犬を飼う人**です。
日本の法令・行政手続き・ペット業界の慣行を前提にした記述があります。
他の国では前提が変わります。

犬種の網羅図鑑ではありません。FCI 公認の約350犬種は扱いません。
診断・治療の手引きでもありません。
緊急時の章も、「どういうときに動物病院へ電話するか」までしか書いていません。

医療・獣医療・法律の記述は、獣医師・トレーナー・専門家と話すための材料です。
専門家の判断の代わりにはなりません。
**いま症状が出ている犬について、この本で自己判断しないでください。**

## 技術構成

- **Astro 7** — 静的サイト生成。出力は完全な静的 HTML
- **MDX** — 本文の形式。`<KeyPoints>` `<Deep>` `<Disputed>` `<Experience>` `<EvidenceBadge>`
  `<Term>` といった独自のコンポーネントを、本文の中で使うため
- **Tailwind CSS v4** — スタイル
- **Pagefind** — ビルド時に索引を作る全文検索。サーバー不要で、日本語も引ける。
  JavaScript を読み込むのは検索ページだけです
- **pnpm** — パッケージマネージャ
- **oxlint / oxfmt**（oxc）— リンターとフォーマッター
- **lefthook** — git hooks。CI は GitHub Actions ではなく手元で回す方針
- **GitHub Actions → GitHub Pages** — `main` に push すると自動でデプロイ（CD のみ）

JavaScript のバンドルは0本です（`dist/_astro` に `.js` が1本もありません）。
テーマ切替とチェックリストだけが、ページに直接書いた小さなスクリプトです。
全29章・35ページのビルドは約8秒（検索の索引作成まで含めて11秒前後）。
