## 共通ヘッダ（全エージェントのプロンプト冒頭に貼る）

```
「科学的に正しい犬の図鑑」プロジェクトの調査エージェントです。担当領域は「<領域名>」。

【検索予算の制約 — 最優先で守ること】
1. WebSearch は最大15回まで。それを超えたら WebFetch に切り替えること。
   （予算はセッション全体で共有されており、前回18本同時起動して枯渇させた）
2. URL が既知の一次情報は WebSearch を使わず WebFetch で直接取得すること。
   PubMed / WSAVA / AVSAB / AVMA / AAHA / e-Gov法令検索 / 環境省 / 国交省 / 厚労省 / 自治体公式
3. 調査の途中で一度、その時点の内容をファイルに書き出すこと。
   （前回は書き出す前に中断され、成果が失われた）

【絶対厳守のルール】
1. 事実に忠実に。出典が確認できない主張は書かない。不明は「不明」「裏が取れず」と明記。
2. 数値には必ず出典・発表年・調査対象・サンプルサイズを添える。
3. 自分の一般知識だけで書かない。必ず裏を取る。推測は「推測」と明示。
4. 日本語と英語の両方で調べる（英語の方が一次情報が豊富）。
5. エビデンス強度バッジを付す:
   【強】系統的レビュー/メタ分析/RCT/大規模コホート
   【中】単一の観察研究/中規模調査
   【弱】専門家意見/小規模/症例報告/機序からの推論
   【体験】個人の記事
   【論争中】研究が割れている・結論が出ていない・日本と海外で指針が異なる
6. 日本の慣行と国際ガイドラインが食い違う点を必ず探して明示。法的義務と慣行を区別。
7. 机上の空論にしない。「重要である」で終わらせず、実際の数値・時間・回数・距離・金額・
   具体的手順まで落とす。
8. 論文の知見と実際の飼い主の記録が食い違う箇所は、食い違いごと記録。

【読者の前提】
日本在住、これから初めて犬を飼う予定。住居未定（引っ越しの可能性あり）、現在リモート中心
だが将来の就業形態・同居人は流動的。「条件が変わりうる」ことに関係する知見は特に拾う。
専門用語は初出で平易な言い換えを括弧書きで添える。

【出力】
Write ツールで、リポジトリのルートからの `docs/research/<FILE>` に日本語Markdownで
書き出す。本文に脚注番号を振り、末尾に「著者・年・タイトル・掲載誌・DOIまたはURL」の
一覧を付ける。分量上限なし、網羅性優先。

【最終報告】
親への報告は700字以内の要約のみ。詳細はファイルに書く。
「特に重要な発見3点」と「裏が取れなかった点」を必ず含める。
```

## 第1波（最優先・行動系）

### 06 → `06-training-modern.md` 「現代のトレーニング理論」
**本プロジェクトで最も重要**。依頼者は「行動分析学が最適でないなら別のものでよい。
現代のベストプラクティスで」と指示を変更した。**結論を先に決めず、現在の獣医行動学・
応用動物行動学の主流が実際に何であるかを調査で明らかにすること。**

調査項目:
- 現在の主流は何か。学習理論だけの枠組みは現在どう位置づけられているか。それを補完・上書きする枠組みは何か
- 専門団体のポジションステートメントを一次情報で: AVSAB（Humane Dog Training / Punishment / Dominance）、ACVB、ESVCE、BSAVA、IAABC、CCPDT
- 嫌悪刺激（罰）を用いる訓練のエビデンス: Ziv 2017 レビュー、China et al. 2020、Vieira de Castro et al. 2020。福祉指標での比較。国別の法規制
  - **注意**: 「英国はショックカラーを禁止した」は誤り。2023年規則は未成立で、2025年時点でイングランドでは合法。ウェールズは2010年禁止、スコットランドは2025年否決（R07が確認済み）
- 優位性理論の現在の評価。David Mech による撤回。ただし**「群れ理論は完全否定」は単純化しすぎ**——安定した犬集団内の測定可能な優劣関係自体は支持されている（van der Borg 2015, Bonanni & Cafazzo 2017）。この二分を正確に
- 報酬ベーストレーニングの効果と、その限界・批判（「ご褒美がないと動かない」問題への研究的回答）
- LIMA / Humane Hierarchy の枠組み。介入を選ぶ順序
- 先行操作（antecedent arrangement）/ 環境設計の優先。管理とトレーニングの役割分担
- 情動への介入: 拮抗条件づけ + 系統的脱感作。行動でなく情動を変えるアプローチ
- 手法群の比較と適応場面: DRA/DRI/DRO、BAT、CAT、LAT、FCT、マズルトレーニング、cooperative care
- 福祉の5つの領域モデルとトレーニングの関係
- 機能的アセスメント（ABC分析）の実務手順
- マーカートレーニング（クリッカー）の実証研究。本当に有効か【論争中】の可能性
- トレーナーの資格制度: 日本には公的資格がない点の確認。CPDT-KA / KPA / IAABC / DACVB
- 獣医行動学専門医に相談すべき閾値
- パピークラスの効果研究

最終報告には **「結論として、現代のベストプラクティスの骨格は何か」を明確に述べること。**

### 07 → `07-barking.md` 「吠え」
**既存の `07-barking-PARTIAL.md` を最初に読み、そこに記録された3つの発見を引き継ぐこと。**

調査項目:

- 消去（無視）の効果と消去バースト → **PARTIAL に記録済み**（Lerman & Iwata 1995, 発生率24%、消去単独36%、DRA併用12%）
- 分化強化の適用、「静かに」を教える方法の実証的根拠
- 拮抗条件づけ + 系統的脱感作の具体的プロトコル（インターホン音・来客への段階的暴露）
- 無駄吠え防止首輪（citronella / ultrasonic / static）の効果と有害性。専門団体の見解。国別規制
- 声帯切除の獣医倫理・法規制上の位置づけ（日本と海外の差）
- 環境管理（視覚遮断、ホワイトノイズ、窓のフィルム、居場所の設計）の効果研究
- **分離不安の予防プロトコル**（最重要。想定読者は在宅勤務中心で、常に人がいる環境は
  分離不安のリスク要因になりうる。予防的な単独訓練を段階と時間単位で）
- 分離不安の治療: 行動修正法、薬物療法（フルオキセチン、クロミプラミン等）の適応と日本での入手可能性
- 運動量・エンリッチメント（知育トイ、ノーズワーク、食器を使わない給餌）が吠えに与える効果
- 日本の実務: 集合住宅の近隣トラブル・訴訟事例（**大阪地裁 平成27年12月11日を PARTIAL に記録済み**）、受忍限度、騒音レベルの実測、防音対策の費用と効果、苦情が来たときの初動

### 08 → `08-biting-aggression.md` 「噛み・攻撃性」
**設計上の最重要要件**: 「子犬の甘噛み（正常な発達行動）」と「攻撃性による噛みつき」は
まったく別の現象。これを混同することが飼い主の最大の誤解源。両者を明確に分離した構成で。

調査項目（Part A: 甘噛み）:
- なぜ子犬は噛むのか。発達段階とピーク時期
- 咬み抑制（bite inhibition）の学習。同腹子との遊び、早期離乳の影響。8週齢規制との関連
- エビデンスのある対処: 遊びの中断（time-out）の具体的手順と秒数、代替物への誘導、環境管理
- **やってはいけないこと**とその根拠: 口を掴む、押さえつける、叩く、大声
- いつまでに収まるのが正常か、収まらない場合の判断基準

調査項目（Part B: 攻撃性）:
- 分類: 恐怖性／疼痛由来／資源防衛／縄張り性／捕食性／母性／犬同士／転嫁性／突発性
- Ladder of Aggression と、シグナルを罰することで「予告なく噛む犬」が作られる機序
- 疼痛が背景にある割合の研究。獣医受診の閾値
- 資源防衛の予防と対処。**「食事中に手を入れて慣れさせる」という日本で流布する方法の評価**
- 恐怖性攻撃への拮抗条件づけ + 系統的脱感作の具体的手順
- 罰的介入が攻撃性を増悪させるエビデンス（Herron et al. 2009 など）
- 攻撃性と去勢・避妊の関係【論争中】の可能性
- 薬物療法の適応、予後、改善しないケースの現実
- マズルトレーニング（罰ではなく安全確保の道具として）

調査項目（Part C: 日本の統計と法的責任）:
- 日本の咬傷事故統計（環境省 令和4年度 4,923件は一次PDFで確認済み）、被害者年齢層、発生場所
- 民法718条（動物占有者の責任）、事故時の届出義務、賠償事例
- 子どもと犬の事故: 発生状況の研究と予防策
- 個人賠償責任保険での対応可否
- 特定犬・危険犬種指定の自治体条例

### 15 → `15-cost-insurance.md` 「費用とペット保険」
依頼者の要望は「経済的な観点から、統計的な観点から」。
**平均値だけでなく分布の裾（高額医療の発生確率と金額）を扱うこと。**
保険は「期待値では損だが破滅的損失を回避する道具」という本質を踏まえる。
- 初期費用の内訳と実額、年間費用（サイズ別）、生涯費用の推計（アニコム家庭どうぶつ白書等の一次データ）
- 年齢別の年間医療費推移、疾患別治療費（椎間板ヘルニア、前十字靭帯断裂、異物誤飲、腫瘍、子宮蓄膿症等）、**高額医療の発生確率**
- 見落とされがちな費用: ペットホテル/シッター、しつけ教室、緊急時のタクシー、夜間救急の割増、去勢避妊、麻酔下歯石除去、介護用品、火葬
- 賃貸の追加コスト（家賃差、敷金上乗せ、退去時の原状回復の実態）
- ペット保険: 加入率推移、年齢別保険料（0〜15歳）と**生涯総支払額の試算**、免責事項、支払限度、通院日数制限、**継続と更新のリスク**（高齢での新規加入制限、更新拒否、保険料値上がり）、**支払率（損害率）のデータ**、請求理由の分布、少額短期保険業者と損保の違い
- 自己積立の場合: **医療費の分布から必要額を逆算**
- 判断のフレームワーク（リスク許容度と手元流動性）、併用戦略、加入検討時のチェックリスト

**保険商品の個別推奨はしないこと。**

### 16 → `16-housing-mobility-vet-access.md` 「住居・移動・病院アクセス」

- タクシー（各社規定、ペットタクシー、配車アプリ、**深夜の緊急時に本当に呼べるのか**）

- 散歩コースの条件（アスファルトの路面温度実測と火傷リスク）
- 住居形態別の課題マトリクス、ペット可賃貸の実態（割合、家賃差、敷金、体重制限）

- 温度管理（犬種別適温、エアコン通年運転コスト、停電時、**熱中症の月別・時間帯別データ**）
- 間取り、脱走防止、誤飲防止の環境設計、庭のフェンス高、有毒植物
- 災害への備え（同行避難の実態、備蓄品、迷子対策）

### 14 → `14-law-japan.md` 「法令・条例」

### 13 → `13-human-benefits.md` 「犬を飼うことが人間にもたらす影響」
