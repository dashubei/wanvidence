# 設計判断ログ 01: 章構成

作成日: 2026-08-26

## 並べ替えの原則

16の調査領域は「学問分野」で分かれているが、章はそれでは並べない。
**読者が実際に判断を迫られる順序**で並べる。依頼者は「これから飼う予定・検討中」であり、
最初の問いは「そもそも飼えるのか」だからである。

したがって、第1部は犬の生物学ではなく**意思決定**から始める。
犬という動物の理解（第2部）は、しつけ（第5部）の土台として必要になる直前に置く。

## 貫通させる軸（全章共通）

想定読者の条件は「住居未定・引っ越しの可能性あり・現在リモート中心・将来の就業形態と同居人は流動的」。
犬の寿命10〜15年に対して前提が動くため、**条件変化に壊れない解**を各章に埋め込む。

- 在宅勤務でも意図的に単独時間を作る（在宅は分離不安の逆リスク要因）→ 14, 17
- 同居人が増えたときのルール不一致対策 → 16, 18
- 引っ越し・環境変化への馴化 → 11, 13
- 収入・世帯構成が変わる前提での保険/積立判断 → 28

## 追記（2026-08-26）: 調査の実物を見て、章の分担を調整した

`docs/research/09-socialization-puppy.md` は16節あり、当初の想定より広い範囲を含んでいた。

### 15章「最初の壁 — 夜鳴きと甘噛み」の範囲を狭める

当初、15章で甘噛みを扱う想定だった。しかし調査08（噛み・攻撃性）が
Part A として甘噛みを詳細に扱っており、**18章と重複する**ことが分かった。

**決定**: 甘噛みの詳細は18章に置き、15章は「迎えた直後の混乱」
（夜鳴き、トイレの失敗、食欲不振、下痢、寝不足）に焦点を絞る。
15章から18章へは参照でつなぐ。

**理由**: 同じ内容を2章に分けて書くと、片方を直したときにもう片方と食い違う。
付録の自動生成と同じ考え方で、**情報源を1箇所にする**。

### 執筆エージェントへの指示に加えたこと

素材の調査ファイルが複数章にまたがる場合、プロンプトに
**「あなたが書くのはこの節だけ」「これは別の章の担当なので書かないこと」**
を明示する。これをしないと、章をまたいで同じ内容が二重に書かれる。
