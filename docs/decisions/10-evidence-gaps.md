# 設計判断ログ 10: エビデンスが薄い領域を、薄いまま書く

記録日: 2026-08-26

## 発見

14章（トイレ・クレート・留守番）を書いた執筆エージェントから、こういう報告があった。

> 出典は素材（調査09の節10・11）に**DOIがある一次研究がなく、すべてURLのみの記載**に
> なった（Wikipedia / AKC / 動物愛護センター等の解説記事のみ）。

確認したところ、14章のエビデンスバッジは**8箇所すべてが `weak`** だった。

## これが意味すること

**クレートトレーニングとトイレトレーニング — 犬を迎えた飼い主が、最初に、必ず、
毎日直面する実務 — には、査読研究の裏付けがほとんど存在しない。**

同種の空白は他にもある:

| 領域 | 状況 |
|---|---|
| クレート／トイレの手順 | 一次研究なし。解説記事のみ |
| 「月齢＋1時間」ルール（排泄の我慢時間） | 出典が複数のブリーダー・保護団体サイトに分散。査読論文なし |
| 「1ヶ月齢あたり5分」ルール（運動量の上限） | 査読研究の裏付けを確認できず。ただし成長板閉鎖の整形外科データとは整合的 |
| 「3-3-3ルール」（保護犬の順応） | 科学的根拠なし。実務家の経験則が起源 |
| フローリングと股関節疾患の関連 | 定量的な疫学研究が英語・日本語とも見つからず。機序の説明は商業サイトのみ |
| 在宅勤務者向けの分離不安予防プロトコル | プロトコル自体を検証した実証研究なし。既存知見の外挿 |

## 判断: 空白を埋めない。空白として書く

これらについて、本書は次の方針を取る。

1. **エビデンスバッジは正直に `weak` を付ける。**
   数が多くても、強く見せるために `moderate` に格上げしない
2. **「査読研究の裏付けは確認できていない」と本文に明記する**
3. **しかし、実務を書かないわけではない。**
   読者は今夜クレートに犬を入れなければならない。「エビデンスがないので書けません」は
   読者を助けない
4. **代わりに「なぜ根拠がないのに使われ続けているのか」を書く。**
   14章にはその見出しが実際にある（「根拠がないのに、なぜ今も使われているのか」）。
   経験則が定着した背景（成長板保護の懸念など、隣接する領域の知見との整合）を示せば、
   読者は「絶対の法則ではないが、外れてもいない目安」として扱える

## なぜこれが重要か

**この本の価値は、強いエビデンスを並べることではなく、強さの違いを見せることにある。**

同じ「犬の飼い方」の情報でも、
大規模コホート研究に支えられた記述（社会化不足と行動問題死亡率）と、
ブリーダーの経験則（月齢＋1時間ルール）が、
同じ顔をして並んでいるのが、既存の情報源の最大の問題だった。

**バッジがすべて `weak` の章があってよい。** それが事実なら、それが最も正確な表示である。

## 読者への提示

この空白は、付録または「この本の読み方」（`/legend`）で、
**本書全体の限界として明示する**こと。
「バッジが `weak` ばかりの章は、その領域の研究が薄いという事実そのものを示している」と。

## 追記: 執筆時に「要求外」として落とした項目（後で補完する）

22章（食事と栄養）の執筆エージェントが、指示リストになかったため深掘りしなかった、
と正直に報告してきた項目。**どちらも実用上は重要なので、記録して後で補う。**

1. **大型犬の成長期のカルシウム上限**
   過剰摂取と骨格疾患の関連。犬種が未定の読者にとって、大型犬を選ぶ場合の
   給餌上の要点になる。現在は AAFCO/FEDIAF の節に1段落の言及のみ。

2. **水分摂取量の目安と、多飲多尿が示す疾患**
   飲水量の異常は腎臓病・糖尿病・クッシング症候群などの早期サインになる。
   素材（調査11）には記述があるが、章には含まれていない。

**教訓**: 執筆指示に「素材のこの節を使え」と列挙する形式は、
**列挙から漏れたものが確実に落ちる**。素材が章より広い場合は、
「列挙は最低限であり、素材にあって読者に有用なものは加えてよい」と
明示したほうがよい。ただし**素材にないものを補うな**という制約は維持する。

## 追記2: 「引っぱり」と「呼び戻し」に、専用の介入研究がない

記録日: 2026-08-26

19章（日常の困りごと）の執筆者からの報告:

> 主素材 `06-training-modern.md` は実質16章の骨格論そのもので、
> **19章が扱う個別の困りごと（引っぱり・呼び戻し）に特化した研究がほぼ存在しなかった。**
> 正直に「専用の介入研究は確認できていない」と明記した上で、
> 16章の一般原則（環境設計 → 分化強化）を適用する形で書いた。

### これが意味すること

**リードの引っぱりと、呼び戻しの失敗** — 犬を飼っている人が日常的に最も困り、
散歩を苦痛に変え、時に事故につながる2つの問題に、**それを直接扱った介入研究がない。**

一方で、トレーニングの**理論**（強化・分化強化・先行操作）には研究の蓄積がある。
つまりこの領域は「原理は分かっているが、個別の課題への適用は検証されていない」状態にある。

### 本書の扱い

執筆者の判断が正しい。すなわち:

1. **専用研究がないことを明記する**
2. **理論から演繹した手順であることを明示する**（16章の4層構造を適用した、と書く）
3. 手順そのものは書く（読者は明日も散歩に行くため）

これは 22章（食事）や 14章（クレート・トイレ）の空白とは性格が違う。
**あちらは「経験則しかない」、こちらは「原理はあるが個別の検証がない」。**
本書では両方とも `weak` バッジになるが、読者には区別が伝わるよう、
「専用の介入研究は確認できていない」という書き方で示す。

### 空白の一覧（追記時点）

| 領域 | 空白の性格 |
|---|---|
| クレート／トイレの手順 | 経験則のみ。一次研究なし |
| 「月齢＋1時間」「1ヶ月齢あたり5分」ルール | 出所不明の経験則 |
| 「3-3-3ルール」 | 根拠なし。実務家の経験則が起源 |
| フローリングと股関節疾患 | 疫学研究が見つからない |
| 在宅勤務者向けの分離不安予防 | 既存知見からの外挿 |
| **引っぱり・呼び戻し** | **原理はあるが、個別の介入研究がない** |
| トリガー・スタッキングの「48〜72時間」 | **引用元を追跡すると別論文にしか辿り着かない** |
