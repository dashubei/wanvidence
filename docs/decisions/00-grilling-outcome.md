作成日: 2026-08-26

このドキュメントは「判断を必ず残す」という指示に基づき、**何を決めたか**だけでなく
**なぜそう決めたか / 何を捨てたか**を記録する。

## 1. 確定した前提（想定読者の条件）

| 項目 | 内容 | 出典 |
|---|---|---|
| 現在地 | これから犬を飼う予定・検討中（飼育経験なし） | Q1 |
| 犬種 | 未定。選び方から知りたい | Q2 |
| 住居 | **未定・引っ越しの可能性あり** | Q3 |
| 生活パターン | 現在リモート中心。同居人・就業形態は将来流動的 | Q4 |

### 導出した最上位の設計軸

> **「今の条件での最適解」ではなく「条件が変わっても壊れない解」を書く**

理由: 犬の寿命は10〜15年。それに対し想定読者の就業形態・同居人・住居はいずれも
「未定」側にある。現在の条件に最適化した記述は、数年内に前提が崩れる
可能性が高く、その時点で図鑑としての価値を失う。

この軸から派生する各章への貫通要件:
- 在宅勤務中でも**意図的に単独時間を作る**予防プロトコル
  （在宅は分離不安の"逆リスク"要因になりうる）
- 同居人が増えたときの**強化随伴性のズレ**（家族間でルールが食い違うとしつけが壊れる）対策
- 引っ越し・環境変化への馴化手順
- 世帯構成・収入が変わる前提での保険 vs 積立の判断

## 3. セッション中の追加要望（7件）とその反映

### 3-1. ペット保険 vs 貯金を経済的・統計的に
独立章として扱う。平均値ではなく**中央値と分布の裾**（高額医療が発生する確率と金額）で
比較する。保険料の生涯総額、加入率、請求データ、免責事項、継続条件、高齢時の
更新・値上げリスクまで含める。

### 3-2. 自動車・動物病院・タクシー（住む場所を決めるとき）
Q3で住居が「未定」と判明したため、これは偶然にも中核テーマになった。
特に **深夜対応の救急動物病院までの距離と到達手段** は、住む場所を決める段階でしか
取り返せない要因であるため、住居章と経済章を貫く軸として扱う。

### 3-3. 法律・条例（2026年8月時点）
独立章。狂犬病予防法（登録・年1回接種の義務と罰則）、動物愛護管理法（マイクロチップ
登録義務）、自治体条例（係留義務・ふん尿処理・ノーリード規制は**条例レベルで自治体差**）、
賃貸の原状回復ガイドライン（国交省）、集合住宅の管理規約。
住居が未定であるため、「自分の自治体で確認する手順」を手続きとして記載する。
一次情報（e-Gov法令検索・環境省・自治体公式）を出典とし、改正による陳腐化の注記を付す。

### 3-4. しつけ章で吠え癖・噛み癖を特に重視
両者を**最大の章**に格上げし、それぞれ独立した調査エージェントを割り当てる。
設計上の要点:
- 「子犬の甘噛み（正常な発達行動・咬み抑制の学習）」と
  「成犬の攻撃性（恐怖性/資源防衛/疼痛由来）」を**混同させない構成**にする。
  この混同が最大の誤解源であり、かつ罰的介入が逆効果というエビデンスが最も強い領域。
- 吠えは機能別（要求・警戒・分離不安・退屈）に分けないと対処が真逆になる。

### 3-5. 専門用語を抑える／机上の空論にしない
- 専門語は初出時に括弧内で平易に言い換える。ただし**語自体は消さない**
  （獣医・トレーナーに相談する際、正しい語を知っていること自体が武器になるため）。
- 「解像度を上げる」の具体化 → 全章に義務付ける編集ルール（後述 4）へ。

### 3-6. 行動分析学が最適でないならそれでなくてよい／現代のベストプラクティスで
**Q7の決定を撤回**し、しつけ章の理論的骨格を事前に決め打ちしない。
調査フェーズで現在の獣医行動学 (veterinary behavioral medicine) の主流を洗い、
その結果に基づいて構成を決定する。
予告した見込み（調査で検証する）: 「学習理論は土台として残るが、それだけでは不十分」に
着地する可能性が高い。ただしこれは仮説であり、調査結果が異なればそれに従う。

### 3-7. 絵文字でなくSVGアイコンライブラリ／UIライブラリ可／UI/UX最優先
Q12の決定を上書き。**Lucide (SVGアイコン) + Tailwind CSS v4** を採用。
- 絵文字を使わない利点: 字形がプラットフォーム依存でなくなる、トーンを統一できる、
  疾患・費用といった真剣な情報の重みが軽く見えるリスクを回避できる。
- 折りたたみは `<details>` ネイティブ要素（アクセシビリティが標準で担保される）。
- インタラクションは Astro islands で最小限に留める。
- a11yルールと日本語タイポグラフィ規定（行間1.8 / 1行37字前後 / ゴシック /
  コントラストWCAG AA以上 / ライト・ダーク両対応）は維持。

### 3-8. 健康長寿・認知症予防
独立領域として調査。犬の認知機能不全（CCD）の予防因子、適正体重維持と寿命の関係、
運動・認知的刺激、歯周病と全身疾患の関連、Dog Aging Project の知見など。
「病気になったらどうするか」ではなく「**健康寿命をどう伸ばすか**」を軸にする。

### 3-9. 読者が前向きになる／行動分析的に強化される設計
ドキュメント自体の設計指示として受領。根拠のある領域である点を重視する
（リスク情報のみを提示すると防衛的回避が生じ行動が変わらない。自己効力感と
セットで初めて行動変容が起きる、という行動変容研究の知見）。
設計原則:
- リスク記述の隣には**必ず対処法を配置**する（孤立した脅し文句を作らない）
- 各章に「今日できる1つのこと」を置き、達成可能な最小単位に分割（シェイピング）
- 「〜してはいけない」を減らし「〜するとうまくいく」に書き換える
- 最初の1週間で**必ず成功する課題**から始める順序にする

### 3-10. 犬を飼うことによる人間側のメリット
独立領域として調査。ただし**この分野は「ペット効果」が過大評価されやすく、
出版バイアスと再現性の問題が指摘されている**。強いエビデンスと弱いエビデンスを
混ぜず、【論争中】マークを使い分ける。「前向きにする設計」と「盛らないこと」を
両立させる（3-9 と 4-7 は矛盾しない）。

### 3-11. ドキュメントを必ず全て残す／事実に忠実に
- `docs/research/` に各調査エージェントの報告を**無編集で**保存する
- `docs/decisions/` に設計判断を残す（本ファイル）
- **統合時に切り捨てた情報も、なぜ切ったかを記録する**

## 4. 全章に義務付ける編集ルール

1. 専門語は初出で括弧内に平易な言い換えを付す。ただし語自体は消さない
2. **実額・実時間・具体的手順**で書く（「費用がかかる」ではなく内訳・月額・生涯総額）
3. リスク記述の隣に必ず対処法を配置する
4. 各章に「今日できる1つのこと」を置く
5. 論文の知見と実際の飼い主の記録が食い違う箇所は、**食い違いごと書く**
6. 日本の慣行と国際ガイドラインの差を明示し、法的義務と慣行を区別する
7. 出典が確認できない主張は書かない。不明なものは「不明」と書く
8. 数値には必ず出典年・調査対象・サンプルサイズを添える
9. 推測は推測と明示する

## 5. エビデンス強度バッジの定義

| バッジ | 定義 |
|---|---|
| 強 | 系統的レビュー / メタ分析 / RCT / 大規模コホート研究 |
| 中 | 単一の観察研究・症例対照研究・中規模調査 |
| 弱 | 専門家の意見・小規模研究・症例報告・機序からの推論 |
| 体験 | 個人の記事・体験談（別ブロックで視覚的に分離する） |
| 論争中 | 研究が割れている / 結論が出ていない / 日本と海外で指針が異なる |

## 9. 公開方針の変更（2026-08-27）

Q5 では成果物を「ローカルのみ。外部公開は行わない」と決めていた。依頼者の判断で
これを撤回し、**GitHub の public リポジトリとして公開し、GitHub Pages でも配信する**
方針に変更した。

本の性格そのものは変えない。**これから初めて犬を飼う一人の読者に向けて書く**という
前提（1節の想定読者の条件）は維持する。変わるのは、その本を誰でも読めるところに
置くという点だけである。

この変更にともなって必要になった作業:
- 「ローカル閲覧専用 / 外部公開しない」と書いてある記述を、事実と合う形に直す
- 特定の個人の私事（住居の状況・勤務形態・世帯構成など）を、本文から想定読者の
  条件という形に書き換える。個人に紐づく事実として残さない
- 体験談の出典が、投稿者を特定できる形になっていないかを確認する
- 医療・獣医療・法律の記述に、「専門家と話すための材料であって判断の代わりでは
  ない」という注意が読者に届く場所にあることを確認する
